## 优先练习的面试追问

以下均为本节练习题，英文用于口述训练，不是公开面经逐字引文。

### Q1. 平均延迟正常，但用户反馈很慢，你看什么？

**英文口述：** How would you investigate latency complaints?

**继续追问：** 是否某个区域、接口或版本受到影响？

**回答要点：** 看 P95/P99、超时、错误率，按维度拆分并用 trace 定位耗时。平均值掩盖尾延迟，不应直接平均不同实例的 P99 得到全局 P99。

### Q2. 一个请求经过多个服务，如何排查失败？

**英文口述：** How would you trace a request across services?

**继续追问：** 日志与指标分别提供什么证据？

**回答要点：** 传播 trace/request ID，集中收集结构化日志，关联依赖调用。指标观察趋势与范围，trace 定位链路，日志解释具体事件。

### Q3. 如何决定 Web 和 worker 的扩缩容指标？

**英文口述：** What signals would you use for autoscaling?

**继续追问：** 只看 CPU 有什么问题？

**回答要点：** Web 可结合吞吐、并发、延迟与资源；worker 结合等待时间、积压和处理速率。设置容量上限、稳定窗口，考虑下游和启动时间。

### Q4. 新版本上线后一个区域错误率上升，怎么处理？

**英文口述：** How would you detect and roll back a bad deployment?

**继续追问：** 数据库变更是否也能直接回滚？

**回答要点：** 按区域与版本比较，灰度发布，设定停止或回滚条件。应用回滚需兼容数据和 schema；不可逆变更要采用分阶段兼容迁移。
