## 优先练习的面试追问

以下均为本节练习题，英文用于口述训练，不是公开面经逐字引文。

### Q1. 设计面向全球用户的图片分发服务。

**英文口述：** Design global image delivery.

**继续追问：** 图片内容、元数据和动态 API 分别走哪条路径？

**回答要点：** 对象存储保存图片，CDN 分发允许缓存的内容，API 管理元数据和权限。关注带宽、命中率、回源流量与热点。此题是本节练习，不是已确认公司真题。

### Q2. 头像更新了，用户仍看到旧图，如何解决？

**英文口述：** How would you invalidate stale CDN content?

**继续追问：** 版本化 URL 和主动刷新各有什么代价？

**回答要点：** 新内容使用新版本 URL，并更新引用；固定 URL 可主动刷新并配置 TTL。URL 查询参数是否区分缓存取决于 cache key 配置。

### Q3. 热门图片爆火，多个边缘节点同时 miss，怎么办？

**英文口述：** How would you protect the origin during a traffic spike?

**继续追问：** CDN 故障后全部回源是否安全？

**回答要点：** 考虑分层缓存、回源请求合并、热点预热与源站限流。fallback 需受容量限制，必要时降级，不能无限回源。

### Q4. 带用户权限的数据能放 CDN 吗？

**英文口述：** Can authenticated content be served through a CDN?

**继续追问：** 如何防止一个用户看到另一个用户的内容？

**回答要点：** 先区分内容分发和共享缓存。私有内容需授权与正确缓存策略；动态 API 也可以经过 CDN，但不代表能安全共享缓存。
