# 05. CDN 内容分发：面试题与答案

## Google / Meta：设计 Dropbox

**参考答案：**

1. 文件内容放对象存储，数据库保存文件 ID、路径、版本、所有者和权限；客户端获得授权后上传，成功后更新元数据。
2. 大文件分块上传并支持断点续传；下载前校验权限，再通过短期签名 URL 和 CDN 分发，限制绕过 CDN 直接访问源站。
3. 客户端通过变更记录同步增量；修改使用版本条件更新，冲突保留独立版本，避免静默覆盖。
4. API 保持无状态，元数据按用户或空间分片；后台异步生成预览，监控同步延迟与回源流量。
