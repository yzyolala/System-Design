## 优先练习的面试追问

以下均为本节练习题，英文用于口述训练，不是公开面经逐字引文。

### Q1. 增加 Web Server 后，用户偶尔掉登录，为什么？

**英文口述：** Why do users lose sessions after scaling out?

**继续追问：** 请求落到另一台机器会发生什么？

**回答要点：** 本地 session 让处理依赖特定实例。将需要跨请求共享的状态外置，任意实例可以根据 session ID 查状态。

### Q2. 为什么不一直使用 sticky session？

**英文口述：** What are the trade-offs of sticky sessions?

**继续追问：** 缩容、实例故障和用户负载不均怎么办？

**回答要点：** 粘性路由可减少改动，但不保证本地状态耐久，会限制流量均衡与故障恢复；讨论复制或外置状态的迁移路径。

### Q3. session、头像、临时上传文件分别放哪里？

**英文口述：** Where should session and uploaded data live?

**继续追问：** 状态外置是否等于全部放 Redis？

**回答要点：** session 放满足有效期与可用性需求的共享存储；图片内容通常放对象存储，元数据放数据库；上传可使用共享对象和持久化任务状态。

### Q4. 共享 session 存储宕机怎么办？

**英文口述：** How would you handle session-store failures?

**继续追问：** 是否允许旧 session？如何注销或撤销 token？

**回答要点：** 设计冗余、超时和故障策略，明确安全与可用性取舍。JWT 可减少部分查询，但撤销、刷新与权限变化仍可能需要服务端状态。
