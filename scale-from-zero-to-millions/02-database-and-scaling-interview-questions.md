# 02. 数据库选择与扩展方式：面试题与答案

## Amazon：设计短链接服务

**参考答案：**

1. 提供创建短链接和跳转两个接口；数据库保存短码、原 URL、创建者和过期时间。
2. 短码使用唯一 ID 编码，或随机生成并用数据库唯一约束处理冲突。跳转时先查缓存，miss 查数据库，检查有效期后返回重定向。
3. Web 服务保持无状态，使用负载均衡扩容；热点链接放缓存，点击统计异步处理。数据库达到容量或写入上限后按短码分片。
4. 创建后立即访问要避免读副本延迟；修改或删除链接要失效缓存。缓存故障时限制回源，保护数据库。

[题目来源](https://www.reddit.com/r/leetcode/comments/1lvnd0t/)

## Meta：设计票务预订系统

**参考答案：**

1. 展示可缓存，但锁座和售卖走权威数据库。通过事务或条件更新将座位从 available 改为 held，保存 hold_id 和到期时间。
2. 支付使用幂等键；成功回调确认锁座有效后改为 sold，重复回调不能重复出票。普通票用原子库存扣减防止超卖。
3. 过期释放检查当前状态与版本，不能释放已售座位；支付成功但锁座失效需要退款或补偿。
4. 热门场次入口排队、限流保护数据库；通知异步发送，售卖正确性不依赖缓存。
