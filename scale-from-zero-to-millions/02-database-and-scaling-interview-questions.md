## 优先练习的面试追问

以下均为本节练习题，英文用于口述训练，不是公开面经逐字引文。

### Q1. 用户资料和订单存储，如何选择 SQL 或 NoSQL？

**英文口述：** How would you choose between SQL and NoSQL?

**继续追问：** 订单需要事务，用户资料主要按 ID 读，你会用同一种数据库吗？

**回答要点：** 列出主要读写、索引、事务边界、查询关系、规模与一致性目标，再评估具体数据库。SQL/NoSQL 名称本身不决定性能或一致性。

### Q2. 流量增加十倍，升级机器还是增加机器？

**英文口述：** When would you scale up versus scale out?

**继续追问：** 哪一层遇到上限？成本和迁移复杂度如何比较？

**回答要点：** 早期 scale up 可减少改动；应用层 scale out 需处理状态和路由；数据库层还要区分读扩展、写扩展、容量扩展。

### Q3. 数据库查询慢，为什么不能直接换 NoSQL？

**英文口述：** Why not replace a slow SQL database with NoSQL?

**继续追问：** 是否检查索引、执行计划、锁竞争、连接池和查询模式？

**回答要点：** 先定位原因。换存储可能保留原有热点和低效访问，并引入迁移成本；只有数据模型与访问模式确实适配时才选择。
