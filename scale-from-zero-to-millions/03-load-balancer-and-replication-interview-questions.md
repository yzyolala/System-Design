## 优先练习的面试追问

以下均为本节练习题，英文用于口述训练，不是公开面经逐字引文。

### Q1. 一台 Web Server 宕机，如何让请求继续成功？

**英文口述：** How do you handle an application server failure?

**继续追问：** 健康检查如何做？LB 自己故障怎么办？

**回答要点：** 检查节点能否服务，摘除失败节点，保留足够冗余容量。LB 也需高可用；在途请求可能失败，重试必须考虑操作是否幂等。

### Q2. 用户修改资料成功，刷新后却看到旧值，为什么？

**英文口述：** How do you provide read-your-writes with read replicas?

**继续追问：** 需要最新数据的请求是否都能读副本？

**回答要点：** 异步复制导致副本落后。关键读可读主库；也可带提交位置或版本，等待副本追上再读取。固定时间读主库只是一种近似办法。

### Q3. 主库宕机，如何切换？会不会丢数据？

**英文口述：** How would you fail over a database primary?

**继续追问：** 旧主恢复怎么办？已成功返回的写入一定存在吗？

**回答要点：** 检测故障、隔离旧主、选择符合复制进度要求的副本、提升并切换路由。异步复制存在丢失最近提交的窗口；同步复制需明确确认条件并付出延迟代价。

### Q4. 增加读副本能解决写入瓶颈吗？

**英文口述：** Do read replicas increase write capacity?

**继续追问：** 复制和分片有什么不同？

**回答要点：** 单主模式的写仍汇聚到主库，副本还要应用写入。复制用于冗余和读扩展，分片将不同数据及其写入分给不同节点。
